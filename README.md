# 行政工作台

网页：[打开行政工作台](https://ranran1001.github.io/admin-workbench/) · [二维码](https://ranran1001.github.io/admin-workbench/qr.svg)

手机和电脑均可打开网页。页面包含今日总览、随手记事与待办、合同节点、用品台账、流程提示、到期通知、CSV／.xlsx 导入和 CSV 导出。记录保存在**当前设备当前浏览器**的 localStorage 中。

## 到期通知

在「今日总览」点击「开启浏览器通知」并允许浏览器权限。网页**打开期间**每分钟检查，且切回页面时检查：待办在今天或逾期、合同与流程进入提前提醒期时，每项每天最多通知一次。系统通知只显示待处理数量，不显示业务详情；实际能否弹出由浏览器与设备权限决定。关闭网页后不会主动推送。

需要网页关闭时提醒，可点击「下载到期日历 .ics」，将文件导入支持 iCalendar 的设备日历。待办以截止日、合同和流程以提醒期第一天（若已进入提醒期，则以今天）生成当地时间上午 9 点的日历事件及提醒。**日历提醒由日历应用负责**，是否显示取决于其通知设置；之后修改或完成事项，已导入的日历事件不会自动更新，须手动处理或重新导入。日历文件包含事项名称与下一步，请妥善保存。

## Excel 导入

「导入与导出」可直接选择标准 `.xlsx` 或 CSV，读取第一个工作表，在本机解析并预览，再按编号追加、跳过重复。建议先导出对应台账 CSV，按其中英文列名建表（例如 `id`、`title`、`due`）；日期使用 Excel 日期单元格或 `YYYY-MM-DD`。不支持旧版 `.xls`、合并单元格模板或任意中文列名自动映射。不上传 Excel 内容；浏览器需支持本地 `DecompressionStream` 解压，若提示不支持可转存 CSV 后导入。

## 换电脑或备份

1. 在旧电脑打开工作台，点击「导入与导出」→「下载完整迁移包 ZIP」。
2. 把下载的 ZIP 拷贝到新电脑并解压。它包括网页程序 `index.html`、全部四类台账数据 `backup.json`、二维码 `qr.svg` 和迁移说明。
3. 在新电脑打开上述工作台网页，点击「导入与导出」，选择解压出来的 `backup.json`，点击「预览恢复内容」。
4. 核对四类台账条数后，点击「确认恢复此备份」。恢复会覆盖新电脑该浏览器现有的全部四类台账，先备份已有记录。
5. 也可单独下载数据 JSON；源代码常驻本仓库，可通过 GitHub 的 Code → Download ZIP 另行下载。建议在网页地址使用程序：某些浏览器直接打开本地 HTML 时会限制本地存储。

设备间**尚无自动同步**，每次迁移更改须重新导出和恢复。CSV／.xlsx 支持分别追加各台账，并按编号跳过重复记录；完整 JSON 恢复会替换全部台账，二者用途不同。浏览器通知权限属于当前设备，迁移后需要重新开启。

本仓库公开，**不要把含真实业务资料的 ZIP 或 backup.json 上传至仓库**。备份文件只保存在用户下载的位置；代码仓库不保存用户填写的记录。当前版本没有独立的账号、API 密钥或其他应用设置。

## 当前边界

随手记事使用本地日期规则生成可编辑待办；尚未接入 AI API、自动公文起草、后台推送或手机系统闹钟。日历导入属于手动转交给日历应用，不是后台推送或实时同步。
