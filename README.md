# 行政工作台

网页：[打开行政工作台](https://ranran1001.github.io/admin-workbench/) · [二维码](https://ranran1001.github.io/admin-workbench/qr.svg)

手机和电脑均可打开网页。页面包含今日总览、随手记事与待办、合同节点、用品台账、采购比价、流程提示、公文起草、到期通知、CSV／.xlsx 导入和 CSV 导出。默认记录先保存在**当前设备当前浏览器**的 localStorage 中。

## 采购比价（网页已实现，无须电商接口）

左侧「采购比价」可新增、修改采购需求，并为同一个需求登记多家商品报价：平台或线下供应商、商品链接、规格、每报价单位包含的统一单位数量、报价单位与数量、单价、运费、优惠、发票情况、到货日和人工核对结果。网页计算总到手价与统一单位的折算单价；实际价格、发票、商品规格和交期需要到商家页面或向供应商核对。审批人、推荐理由与审批结论仅用于**记录真实发生的审批**，网页不能代替单位的采购审批。

实际批准后，可按订单号分批确认验收，每次验收自动新增一笔用品入库流水并关联流水编号；未批准时不能入库。用品台账新增「单位」，旧流水默认按「件」处理，旧 CSV 无单位列仍可导入；同名不同规格请区分名称，库存按名称和单位汇总。新设备初始有三项虚构需求、每项三家报价；已有本机记录的设备不会自动混入示例，可在「采购比价」点「加入三组虚构采购示例」，该操作只追加缺失的示例且不覆盖现有记录。**示例不是平台实时商品或真实价格。**采购 CSV 可单独导出，采购需求／报价／审批／验收进入完整 JSON／ZIP 备份及已配置的云端同步。先前独立发放的四页采购 Excel 模板是参考表，**当前不能直接导入采购模块**。

目前不连接淘宝、拼多多或其他商城 API，不会自动抓价、自动推荐全网最低价或自动下单；不需要为这一版填写新密钥。

随手记事输入框中的文字会暂存在本机，以防误关网页；它还不是正式待办。核对日期并点击「加入工作队列」后，才会进入完整备份和已配置的云端同步。普通浏览器的本机数据通常跨会话保留；无痕浏览或清理网站数据可能清除它。

## 公文起草和云端同步

「公文起草」可填写已确认事实、选择参考例文、整理起草提示词、选择 DeepSeek 深度思考或快速起草、编辑生成的草稿并保存例文。内置一篇虚构通知例文。例文会进入完整备份；旧版 v1 备份仍可导入。DeepSeek 调用需要自己配置 Supabase 项目、登录并部署服务端函数，API 密钥只存放在 Supabase 的 Secrets 中。未完成配置时，页面仍可在本机整理起草要求和保存例文，但不能直接生成 AI 草稿。

「多设备同步」也需要自己配置 Supabase 项目。登录后首次选择上传本机或下载云端；保存时先写本机，云端确认后才显示「已同步」。在线设备通过数据变更订阅接收更新，切回网页时再次检查；离线修改会等待上传，发生两端冲突时暂停上传并提供备份和选版本操作。已配置的同步数据包含采购需求及报价，旧云端记录没有采购数组时会按空数组兼容，后续修改时写入云端。**在项目未配置并完成登录前，不存在实时同步。** 完整步骤见 [云端配置说明](cloud/云端配置说明.md)。

## 到期通知

在「今日总览」点击「开启浏览器通知」并允许浏览器权限。网页**打开期间**每分钟检查，且切回页面时检查：待办在今天或逾期、合同与流程进入提前提醒期时，每项每天最多通知一次。系统通知只显示待处理数量，不显示业务详情；实际能否弹出由浏览器与设备权限决定。关闭网页后不会主动推送。

需要网页关闭时提醒，可点击「下载到期日历 .ics」，将文件导入支持 iCalendar 的设备日历。待办以截止日、合同和流程以提醒期第一天（若已进入提醒期，则以今天）生成当地时间上午 9 点的日历事件及提醒。**日历提醒由日历应用负责**，是否显示取决于其通知设置；之后修改或完成事项，已导入的日历事件不会自动更新，须手动处理或重新导入。日历文件包含事项名称与下一步，请妥善保存。

## Excel 导入

「导入与导出」可直接选择标准 `.xlsx` 或 CSV，读取第一个工作表，在本机解析并预览，再按编号追加、跳过重复。建议先导出对应台账 CSV，按其中英文列名建表（例如 `id`、`title`、`due`）；日期使用 Excel 日期单元格或 `YYYY-MM-DD`。不支持旧版 `.xls`、合并单元格模板或任意中文列名自动映射。不上传 Excel 内容；浏览器需支持本地 `DecompressionStream` 解压，若提示不支持可转存 CSV 后导入。

## 换电脑或备份

1. 在旧电脑打开工作台，点击「导入与导出」→「下载完整迁移包 ZIP」。
2. 把下载的 ZIP 拷贝到新电脑并解压。它包括网页程序 `index.html`、四类原有台账及采购记录的 `backup.json`、二维码 `qr.svg` 和迁移说明。
3. 在新电脑打开上述工作台网页，点击「导入与导出」，选择解压出来的 `backup.json`，点击「预览恢复内容」。
4. 核对四类台账、例文和采购需求条数后，点击「确认恢复此备份」。恢复会覆盖新电脑该浏览器现有记录，先备份已有数据。
5. 也可单独下载数据 JSON；源代码常驻本仓库，可通过 GitHub 的 Code → Download ZIP 另行下载。建议在网页地址使用程序：某些浏览器直接打开本地 HTML 时会限制本地存储。

未配置云端的设备之间**没有自动同步**，每次迁移更改须重新导出和恢复。CSV／.xlsx 支持分别追加原有四类台账，并按编号跳过重复记录；采购模块当前支持页面录入与 CSV 导出；完整 JSON 恢复会替换四类台账、例文库和采购记录。旧版 v1／v2 JSON 仍可导入，采购记录会初始化为空。浏览器通知权限属于当前设备，迁移后需要重新开启。

本仓库公开，**不要把含真实业务资料的 ZIP 或 backup.json 上传至仓库**。备份文件只保存在用户下载的位置；代码仓库不保存用户填写的记录。云端配置页面只接收项目公开参数；DeepSeek 密钥须存放在自己项目的服务端 Secrets 中。

## 当前边界

随手记事使用本地日期规则生成可编辑待办；AI 公文生成和跨设备同步只有在用户自行完成云端部署后才能使用。尚无后台推送或手机系统闹钟。日历导入属于手动转交给日历应用。
